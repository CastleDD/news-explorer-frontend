# WTWR (What to Wear?): Back End

This is the front end of the News Explorer application, a search engine that allows users to search keywords and view news articles containing those keywords. This client side React application allows users to register, log in, and manage articles saved to their liking, and also the ability to remove articles.

The front end interacts with the NewsExplorer API server and provides a clean, responsive user interface for managing articles based keyword searched.

## Features

-Simulated user registration and login using local storage
-Search for articles by keyword
-Save and unsave articles from personal saved articles page
-View articles
-Responsive modals and card layout
-Logout functionality
-Protected routes for authenticated users
-Mobile menu

### Technologies

- React.js – Front-end JavaScript library for building UI components
- React Router – Client-side routing and protected routes
- JavaScript (ES6+) – Application logic and API interaction
- CSS – Responsive styling using Flexbox and media queries
- REST APIs – Fetching news articles from an external news API
- Local Storage – Persisting user authentication and saved articles
- Vite – Development server and build tool
- Modular component architecture – Reusable and maintainable project structure
